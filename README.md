# ProvisionPoint Teams App

Official Microsoft Teams application packages for **ProvisionPoint**.

This repository provides downloadable Teams application packages for supported ProvisionPoint production environments.

## Download

Download the appropriate regional package from the **[Releases](../../releases)** section.

### Production Packages

| Region         | Package                                |
| -------------- | -------------------------------------- |
| Australia      | `ProvisionPoint-AU-TeamsApp-x.x.x.zip` |
| Switzerland    | `ProvisionPoint-CH-TeamsApp-x.x.x.zip` |
| European Union | `ProvisionPoint-EU-TeamsApp-x.x.x.zip` |
| United Kingdom | `ProvisionPoint-UK-TeamsApp-x.x.x.zip` |
| United States  | `ProvisionPoint-US-TeamsApp-x.x.x.zip` |

Always use the latest release unless instructed otherwise by ProvisionPoint Support.

## Installation

1. Download the ZIP package for your ProvisionPoint region.
2. Open the Microsoft Teams admin center.
3. Upload the package using your organization's Teams app deployment process.
4. Make the application available to the appropriate users.

**Do not extract or modify the ZIP file before installation.**

Each package contains the Microsoft Teams application manifest and icons configured for its corresponding ProvisionPoint environment.

## Support

For assistance selecting or deploying the correct package, contact ProvisionPoint Support through your usual support channels.
